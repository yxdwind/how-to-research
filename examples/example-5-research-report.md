# 案例 5：写一份经得起追问的调研报告

> 场景标签：调研报告 · 写作 · 边调研边起草
> 涉及章节：ch11（调研报告）、ch03（调研的准备）、ch02（求实求真求是）

## 场景

调研做完了，材料一堆，报告写不出来——或者写出来被老板一句"所以呢？"问死。本书第十一讲的打法是：报告主要不是"写"出来的，是调查出来、研究出来的；而且要边调研边起草。

## 你怎么说

> 调研材料都在这里（访谈记录、数据、笔记）。用怎样调研的方法帮我把报告写出来：先定类型（情况/问题/经验/研究哪一类），再按"边调研边起草"的规矩搭结构，写完用书里的标准自检。

## AI 执行路径

1. 读 `chapters/ch11-research-report.md`（真实深高、五类写法、五条心得、五分写五分改）
2. 先定报告类型——类型错则全错（问题类最忌"四段式"）
3. 挑干货：三四十个情况里能用上十个八个，五六十个问题能用上一二十个就不错——敢于舍弃
4. 按"有一条写一条"并列结构搭问题类报告，危害原因揉进去写
5. 用五条心得自检：主题聚焦？结构简约？表述朴实？观点鲜明？修改几轮了？

## 方法论如何落地

- **主题聚焦**：一事调研一题一报告；46 位受访者的素材也只聚焦一个问题
- **结构简约**：五部分砍成三部分、七条砍成五条，开头语结束语可全删；层次只用两级
- **观点鲜明**：有就是有、没有就是没有；用群众/用户原话和数据说话，官话一句不留
- **修改**：热写稿冷改稿，改的是主要内容、大小标题、分析角度——不止咬文嚼字

## 关键输出片段（模拟）

```markdown
自检报告（按书中标准逐项过）：

主题聚焦 ✗ 一篇里塞了"渠道+定价+组织"三个主题
  → 拆：本篇只回答"为什么下沉市场跑输"

结构 ✗ 用了"基本情况/主要问题/危害原因/意见建议"四段式
  → 改并列式：有一条写一条，危害原因揉进对应问题里
  → 头重脚轻问题自动消失

表述 ✗ "总体向好，但仍存在一定不足"——空洞
  → 改：用具体数据与原话（"6/8 家经销商提到账期超过 45 天"）

观点 ✗ 结尾"建议重视"等于没说
  → 改：三条建议每条落到动作+责任+时限

修改轮次 ✗ 改了 1 遍
  → 至少三轮：热写稿→冷改→再过筛（何其芳式逐项过在 how-to-write）
```

## 书中依据

- "高质量的调研报告主要不是写出来的，而是调查出来、研究出来的"（ch11）
- "真实深高"四字标准：真是底线、实是关键、深是方向、高是站位（ch11）
- 问题类报告警惕"四段式"三大弊端，用并列结构（ch11）
