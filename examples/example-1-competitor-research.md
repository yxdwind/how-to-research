# 案例 1：做一次竞品分析调研

> 场景标签：市场调研 · 竞品分析 · 组合拳
> 涉及章节：ch02（调研的导向）、ch03（调研的准备）、ch04（文献调研）、ch06（抽样调研）、ch11（调研报告）

## 场景

老板让你调研一个竞品："下周给我一份竞品分析。"常规做法是搜一堆网页拼 PPT——按本书方法论，第一步不是搜，而是定课题、精练主题、选方式、拟纲目。

## 你怎么说

> 用怎样调研这个 skill，帮我做竞品 X 的调研。按书里的流程来：先帮我精确课题和主题（小切口大文章），再选调研方式的组合拳，拟好调研纲目，然后开工。

## AI 执行路径

1. 读 `chapters/ch03-preparation.md`（课题四类型、方式三着眼点、纲目设计）——先磨刀
2. 读 `chapters/ch04-document-research.md`——文献调研三渠道并查打地基
3. 读 `chapters/ch06-sampling-typical-case.md`——竞品样本怎么选（典型调研：先进/中间/落后都要看）
4. 产出调研纲目后向你确认，再进入信息收集与报告起草

## 方法论如何落地

- **课题定位**：不贪大求全做"完整竞品分析"，切小口——如"竞品 X 的定价与渠道策略为何在下沉市场跑赢"
- **主题校准**：主题先行但防臆想——先文献调研摸底，再锁定靶心
- **方式组合拳**：文献调研（官网/财报/招聘/评价数据）＋ 典型调研（选高中低三类用户访谈）＋ 必要时问卷量化
- **纲目即报告预演**：一二级标题＋调研要点一次列清，"开始就在一个轨道上运行"

## 关键输出片段（模拟）

```markdown
调研纲目（v0.1，报告提纲的"前身"）：
一、竞品 X 的市场位置（基准数据：份额/增速/区域分布）
   要点：能量化尽量量化；排除法聚焦
二、其打法拆解（产品/定价/渠道三选一深挖，本期定价）
   要点：4 个"多少"：客单多少、折扣多少、渠道分成多少、补贴多少
三、它为什么在下沉市场跑赢（3 个假设，逐个验证）
   要点：要有预测研判要求（第 3 条）
四、对我们的三点启示（每条落到动作）

方式组合：文献调研（当周完成）→ 3 类用户各 2 人典型访谈 → 不下结论
```

## 书中依据

- "首要任务是定题……开一个小切口，做一篇大文章"（ch03）
- "调研方式没有万能钥匙，只有专用钥匙"（ch03）
- 陈云纲目四启示：视野、量化、研判、排除法（ch03）
- 典型调研"先进/落后/中间"三类都看（ch06）
