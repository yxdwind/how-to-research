# 范文拆解卡：问卷/量表（questionnaire）

> 素材来源：《怎样调研》第五讲原书实例。本卡是拆解，不是原文；设计前通读本卡 + ch05。
> 核心心法先记住：**问题必须"中标"、答项必须"达标"**——问卷成败在设计，不在发放量。

## 卡 1｜一份失败问卷的逐题诊断（ch05 反面样板）

| 维度 | 拆解 |
|------|------|
| 场景 | 某问卷评价市领导班子，四题皆有硬伤，统计出来难以使用 |
| 硬伤清单 | ①"总体评价"选项却像评个人——标的错位；②"有想法没办法"把正负评价塞进一个选项——互斥破坏；③四个"关心"类选项调研对象可能都会打钩——等于没问；④答卷说明允许全选——直接产生矛盾/无效答卷 |
| 可复用 | 设计完做"敌意审查"三连问：问句中立吗？选项同等级互斥吗？全选即废卷吗？ |

## 卡 2｜毛泽东 1955 年粮食征购六问（ch05 正面样板）

| 维度 | 拆解 |
|------|------|
| 场景 | 起草征购通知所附调查问题，前五问都要用百分比回答 |
| 骨架 | 连"叫唤缺粮的人"都分"真叫唤""假叫唤"各占百分之几——定性判断直接嵌入量化设计 |
| 结构诀 | 一个数据兼作两用：真假定性与比重定量；问的都是"能量化回答"的问题 |
| 可复用 | 每题先问自己"我要的答案是什么形状"——要比较就封闭、要归因才开放 |

## 合成示范（原书无此稿，按原书标准写就，供模仿口径用）

> 场景：SaaS 产品客户续约前满意度摸底（10 题，B 端用户，线上发放）。素材假设为用户提供的产品与客户分层信息。

```
XX 产品年度使用情况调研（客户版）

说明：本问卷用于改进下一年度服务，约 3 分钟。所有题目按单人视角
作答即可；除标注多选外均为单选。感谢配合。
（W3 起手：为什么调、怎么答，一次说清）

第一部分 使用与价值
1. 您所在团队目前有多少人在用 XX 产品？（单选）
   A. 1-5 人  B. 6-20 人  C. 21-50 人  D. 50 人以上
   （答项同等级、互斥、覆盖完备——W5/W6）
2. 过去 3 个月，您个人平均每周使用频次？（单选）
   A. 几乎每天  B. 每周 2-4 次  C. 每周 1 次  D. 更少
3. 【多选，最多选 3 项】下列哪些功能对您的日常工作真正有用？
   A. 报表导出  B. 权限管理  C. API 集成  D. 模板库  E. 移动端
   （允许多选、不允许全选，且限 3 项防敷衍——W8）

第二部分 满意度（李克特五级：非常满意/满意/一般/不满意/非常不满意）
4. 您对系统稳定性的满意度？
5. 您对客服响应速度的满意度？
6. 您对价格与价值匹配度的满意度？
   （每题单一维度、正负中性齐备，不把两件事塞进一问——W4/W7）
7. 续约意愿：贵司明年续约的可能性？
   A. 肯定续  B. 可能续  C. 不确定  D. 可能不续  E. 肯定不续
   （正负中性齐备——缺了 D/E 就是"被满意"）

第三部分 开放题（点缀，1 题）
8. 如果明年只能保留一个功能，您留哪个？为什么？
   ______________________
   （封闭为主、开放点缀；问的是归因，不是泛泛"有何建议"——W9）

9. 【仅 option C/D 者作答】您或同事转投替代品时，最先比较的是：
   A. 价格  B. 功能覆盖  C. 数据迁移成本  D. 服务响应
   （跳转逻辑把敏感题问给对的人——标的性 W1）

敌意审查记录（W13，交付前必填）：
- 问句中立？——第 3/8 题无预设立场；第 6 题未预设"价格合理"。
- 选项同等级互斥？——第 1 题按人数档位、第 7 题按意愿强度，无跨级。
- 全选即废卷？——全卷无全选；第 3 题限 3 项。
- 溯源：题目依据＝客户成功部 9-10 月工单分类记录（内部材料）。
```

**示范稿拆解**（自己对照）：说明段先立规矩（单人视角、单选多选分明）；每道封闭题的答项都在同一等级上互斥；李克特部分一题一维度；正负中性齐备贯穿（第 7 题敢放"肯定不续"）；开放题只留一题且带归因钩子；敏感的流失题用跳转逻辑问对人；交付时附敌意审查记录——这就是"设计完自检一遍"的动作化。

## 使用规则

1. 设计前：本卡 + ch05 + rubrics/questionnaire.md；对象框问题先过 ch06（标的不对，内容再好也没用）。
2. 示范稿题目仅为格式示例，套用时按真实专题重写并注明设计依据来源。
3. 需要态度量化的场合先选量表四型（总加/李克特/语义差异/社会距离），再落成题目。
4. 网络问卷交付时提醒：权威性、精确性有限，宜作社情民意手段，慎重用于系统分析（ch05"关联"）。
5. 有本地真实问卷时放 `models/local/`，设计前优先读。
