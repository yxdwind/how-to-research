# local/templates —— 本地范文填空模板

把真实范文变成拆解卡的最短路径：复制对应模板 → 重命名 → 逐项填空 → 移到 `models/local/` 根目录即生效。产出同一类成果时，**local 真实范文优先于内置卡**。

## 模板清单

| 模板 | 产出物类型 | 对应内置卡 |
|------|-----------|-----------|
| [plan.md](plan.md) | 调研方案/纲目 | ../../plan.md |
| [questionnaire.md](questionnaire.md) | 问卷/量表 | ../../questionnaire.md |
| [interview.md](interview.md) | 访谈/座谈/蹲点备装 | ../../interview-guide.md |
| [report.md](report.md) | 调研报告 | ../../research-report.md |

## 三条约定

1. **命名**：`类型-场景标识.md`，如 `report-县域消费摸底.md`、`plan-商圈进入.md`；模板本身留在 templates/ 内，不混入 local 根目录。
2. **四段结构**：每张卡＝骨架（照抄范文的块结构）＋要点（做对了什么）＋数据位（关键数字及用法）＋禁忌（踩过的坑）；【】内为填空提示，交付前删净。
3. **红线**：local 卡含真实业务数据，只放本地自用、不得入仓库；引用他人范文先确认版权。
