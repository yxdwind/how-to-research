# 范文拆解卡：调研方案/纲目（plan）

> 素材来源：《怎样调研》第三讲原书实例。本卡是拆解，不是原文；产方案前通读本卡 + ch03 + cheatsheet 选择树。
> 核心心法先记住：**好的纲目就是报告的初步提纲**——方案起步就在"调研→报告"一条轨道上运行，不留双轨制。

## 卡 1｜陈云 1973 年国际金融调研纲目（ch03）

| 维度 | 拆解 |
|------|------|
| 场景 | 美元与黄金脱钩之际，给中国人民银行开出十个问题的调研纲目 |
| 骨架 | 十问递进：发行量与储备现状 → 世界供给 → 资金分布 → 危机标志 → 各国应对与危机间隔 → 矛盾焦点 → 解法 → 赤字构成 → 近远期估计 → 透支便利的利害 |
| 结构诀 | ①有国际视野；②能量化的尽量量化（纲目里有八个"多少"）；③有预测研判要求（第九、十问）；④用排除法聚焦（"除了……以外"） |
| 可复用 | 纲目不是问题清单，是一条从现状到研判的证据链；每问都要"可被调查回答" |

## 卡 2｜田家英三组安排——多组调研的部署样板（ch03）

| 维度 | 拆解 |
|------|------|
| 场景 | 1961 年毛泽东布置农村调查：三个组各七人 |
| 骨架 | 五要素一次配齐：任务明确｜人员精干｜地点有代表性｜对象有典型性｜时间适中（十至十五天）；组内再分——一组查最坏的生产队、另一组查最好的，中间队不查 |
| 结构诀 | 好差两头对比设计前置到部署层；读哪本书都定好——准备细到动作级 |
| 可复用 | 多点调查的分工表：任务/人员/地点/对象/时间五列，缺一列就是没部署完 |

## 合成示范（原书无此稿，按原书标准写就，供模仿口径用）

> 场景：连锁茶饮品牌拟进入某二线城市，用户要一份市场进入调研方案（约 1200 字）。素材假设为用户提供的品牌与城市基本信息。

```
XX 品牌进入 X 市市场调研方案

一、主题与导向
主题（一句话）：X 市核心商圈能否支撑 XX 品牌前 3 家直营店盈利。
导向：为开店决策服务；成功标准＝给出"进/不进/怎么进"的可执行依据。
课题类型：专项性课题（防"万金油"：只答进入可行性，不兼答品牌全案）。

二、方式组合（每种一理由）
① 文献打底：城市消费数据、商圈客流、竞品门店与扩张动态——桌面可得，
先查完再定补哪些（三渠道：内部经营数据/行业报告/公开点评与地图数据）。
② 蹲点观察（2 家标杆店 + 1 家同价位新店）：按"选雀法"选点——
头部学打法、同价位看存活、一头一尾做对比；记录时段客流、客单、复购信号。
③ 小座谈（每店 3-5 人，共 2 场）：找真喝过的人谈口味与价格感受；
屏退品牌方人员；从小问题切入（"上次点单为什么选这家"）。
④ 目标客群快问（拦截 100 人，封闭类为主）：量化价格带与频次，
答项同等级互斥、正负中性齐备、不允全选。

三、纲目（报告提纲预演）
一、X 市目标商圈容量——多少客流、多少同类店、多少空铺（量化）
二、竞品格局与价格带——头部占多少、同价位存活几家、均价差多少
三、目标客群画像与支付意愿——频次多少、可接受价格上限多少
四、进入策略与首店测算——首店选址、投资多少、多久回本（预测研判项）
五、风险与不进入条件——出现哪些信号即放弃（排除法聚焦）

四、部署（五要素）
任务：出进/不进决策建议｜人员：2 人桌面 + 2 人外勤｜地点：3 个核心商圈
对象：标杆店顾客、同价位店顾客、商圈白领｜时间：14 天（外勤 6 天）
动员：外勤前半天对齐纲目与记录模板，讲方法不讲意义。
预案：蹲点发现新业态（如无人茶饮柜）即跳出纲目增补一问。

五、成果与转化
产出：决策建议报告（≤5000 字）。转化：直达开店委员会评审；
紧急信号（如商圈大面积撤店）出现时先电话/即时通报，不等成文。
```

**示范稿拆解**（自己对照）：主题是一句话可判成败的（"能否支撑 3 家店盈利"）；每写一种方式就给理由（专用钥匙，不是方式展览）；纲目五块几乎每块带"多少"（陈云量化味），第四块是预测研判项、第五块是排除法；部署五要素逐项落地，两头对比放在部署层；末尾转化出口预置——"给谁用、紧急怎么办"。

## 使用规则

1. 产方案前：本卡 + ch03 + rubrics/plan.md；方式定位先用 cheatsheet 选择树。
2. 示范稿中的数字仅为格式示例，套用时必须全部替换为真实素材并保留出处标注习惯。
3. 用户带着预设结论立项时，方案中必须写明"证伪同样要报"（防臆想观点当主题）。
4. 有本地真实方案时放 `models/local/`，产方案前优先读。
