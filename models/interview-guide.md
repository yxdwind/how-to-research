# 范文拆解卡：访谈/座谈设计（interview-guide）

> 素材来源：《怎样调研》第七、九、十讲原书实例。本卡是拆解，不是原文；备装前通读本卡 + ch07/ch09。
> 核心心法先记住：**找对人比谈得久重要**——知道真情＋敢说真话，缺一条谈话就是空转。

## 卡 1｜寻乌调查——讨论式调查会全套动作（ch09）

| 维度 | 拆解 |
|------|------|
| 场景 | 1930 年寻乌，34 天；从与县委书记一夜长谈起步，访商会前会长（"打着灯笼难找的行家"）、借县志、杂货店以茶为引访谈 |
| 骨架 | 商业调查会 8 大项、寻乌城 25 个子目（大纲＋细目＋子目三级）；开场白承诺"记下后念给大家听，不对的地方请大家提出来"；总结会 50 多人开两天 |
| 结构诀 | ①行家当先生，不看头衔看知情度；②纲目细到"洋布/土布/绸缎"子目级，防漫谈会；③记录当场验证——念给大家听就是核对；④边干活边谈（帮拔稗草时问山林分配） |
| 可复用 | 三级纲目模板：领域（大纲）→ 品类（细目）→ 具体项（子目）；开场白三件套＝为什么谈/怎么记/可纠错 |

## 卡 2｜兴国调查——破冰与共同确认（ch09）

| 维度 | 拆解 |
|------|------|
| 场景 | 1930 年，8 位农民一星期，每天两三次会常至深夜 |
| 骨架 | 第一天只谈家常"脸上没有一点笑容"→ 请吃饭、盖宽被之后"无话不谈"；毛泽东亲自记录，结论征得 8 人同意才写下，记下的内容反复讲给农民听直到认可 |
| 结构诀 | ①破冰靠诚意细节而非说教；②结论共同确认——记录即验证；③8 个家庭的微观样本得出结构性结论（1% 地主 + 5% 富农占地 80%） |
| 可复用 | 破冰时间预算：第一天别想着出干货；记录模板带"念给对方确认"栏 |

## 卡 3｜陈云青浦蹲点——小切口算细账（ch07）

| 维度 | 拆解 |
|------|------|
| 场景 | 15 天蹲点小蒸，住亲戚家、上午走访农户：看 10 个养猪场，问母猪细账（每天吃多少饲料、能否吃到青草、奶水不足怎么办）；又和老农算双季稻细账 |
| 骨架 | 两个具体问题解剖成三份报告：《母猪也应该下放给农民私养》《种双季稻不如种蚕豆和单季稻》《按中央规定留足自留地》——双季稻账：寄秧少产 150 斤＋多用稻种 40 斤＋少收豆麦 80-100 斤等，合计折损 310-330 斤稻谷，结论"种双季稻不如种蚕豆和单季稻" |
| 结构诀 | 细账是最硬的证词——把"划算不划算"问到斤两；蹲点盯"现在进行时" |
| 可复用 | 蹲点提问链：现在怎么干 → 哪里疼 → 这笔账怎么算 → 怎么干更好 |

## 合成示范（原书无此稿，按原书标准写就，供模仿口径用）

> 场景：用户下周走访 3 家加盟门店（1 家头部店、1 家中间店、1 家尾部门店），要把"让人说真话"设计好。素材假设为用户提供的门店与人员名单。

```
3 家加盟门店走访备装（半天/店）

一、对象策略（I1/I2/I4：找对人、屏退压制者、多路印证）
- 每店约谈：店长 1（单独）、店员 1-2（店长退场后）、熟客 1-2（店内自然状态）
- 屏退设计：加盟商督导不在场时才谈分账与考核话题；店员访谈换到后仓/休息区
- 印证：3 店同类问题交叉比对；店长说法与 POS 台账、排班表对账

二、纲目（I5：大纲→细目→子目，按纲目发问防漫谈）
1 经营现状：客流（工作日/周末各多少）→ 客单 → 复购信号
2 与总部关系：供货 → 考核 → 分账（敏感，压后；子目如"促销费用谁垫"）
3 人的状态：排班强度 → 流失 → 培训
4 单店判断：最想改的一件事 → 需要总部给什么

三、话术要领（I6/I7：小问题切入，开场白三件事）
- 开场白（对每人均说）："今天来是想把门店真实经营情况带回去，
  记了笔记会念给你听，说得不对的地方你直接纠正。"（为什么谈/怎么记/可纠错）
- 切入从生活与具体事起：先聊"今天备货比上周多还是少"，再滑向经营；
  "分账您觉得规矩吗"这类问题只在单独场合问。
- 听到"都挺好的"→ 降维追问："上个月哪天最难？那天发生了什么？"
  （从具体一天进，不跟套话纠缠）

四、防排演（I10）
- 不按总部给的路线走：三店顺序到店前再定；每店留 40 分钟"未安排时段"
  看后仓、看交接班；午餐在门店周边大众餐馆自费解决，不接受总部或加盟商安排的招待（独立性纪律：不接受利益相关方安排）。

五、记录与回收（I9/I13）
- 记录模板四栏：原话（引号）｜我的追问｜对方神态语气｜待核实
- 当晚回收：三店笔记合并，"话里有话"标注，与台账矛盾处列清单，
  次日补一通电话核实后再进报告。
```

**示范稿拆解**（自己对照）：对象策略先于话题设计（找谁、屏退谁、怎么印证是第一段）；纲目三级展开且敏感话题压后；开场白三件套原话给出、可照念；每个话术都带"遇到套话怎么办"的降维追问；防排演落成具体动作（顺序不定、留白时段、自费吃饭）；记录模板带神态栏与待核实栏——回收动作（当晚合并、次日核实）写死在计划里。

## 使用规则

1. 备装前：本卡 + ch07/ch09/ch10 + rubrics/interview.md；规模按目标选（求共识大座谈、求真话小座谈/个别谈）。
2. 示范稿中的门店场景仅为格式示例；蹲点任务学卡 3 的提问链，把"账"问到斤两。
3. 个案只提供线索不下结论：单点观察在产出里标注"线索级"（ch09 电梯访谈原则）。
4. 有本地真实提纲时放 `models/local/`，备装前优先读。
